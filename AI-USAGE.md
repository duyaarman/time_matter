### AI-assisted code I understand best

#### TaskService

**File:**  
`lib/services/task_service.dart`

**Commit:**  
https://github.com/duyaarman/time_matter/commit/feb48d3

`TaskService` manages the task data used by TimeMatter. It contains a list
of `Task` objects and provides methods for adding, updating, completing, and deleting tasks.

The service extends `ChangeNotifier`. When a task is changed, it calls
`notifyListeners()` so that parts of the application using the service can update their UI.

I understand this structure because it keeps the task-management logic in one place instead of putting the same logic into each screen.

For example, `addTask()` adds a task to the list, `updateTask()` finds an existing task using its ID and updates it, `toggleTask()` changes the completion state, and `deleteTask()` removes the task.
